This release adds a new stateless reverse proxy component called GpuBroker-Proxy. The proxy exposes an OpenAI-compatible /v1/* surface alongside Ollama's native /api/* endpoints. Traffic routes through a model-to-backend registry.

The proxy acquires a broker lease per generation request (mb=0 to avoid double-counting passive VRAM telemetry). The proxy denies requests using a 429 response and a Retry-After header when the GPU reaches full capacity. The proxy fails open if the broker becomes unreachable. Responses stream through the proxy. Each response releases its lease only after a full drain.

We found a routing gap while testing live traffic. Paths without a model declaration now pass straight through instead of returning 404 silently. This change covers /api/ps, /v1/models, and other paths.

This implementation includes 15 unit tests. We verified it on real hardware with GpuBroker, Ollama, and Headroom running concurrently.
